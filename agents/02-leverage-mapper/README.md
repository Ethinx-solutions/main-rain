# Leverage Mapper Agent

## Purpose
Identify the highest leverage shift opportunities by analyzing situation analysis and mapping potential impact areas.

## Inputs
- Situation analysis from Agent 01
- User goals and objectives
- Current workflow inefficiencies

## Outputs
- Business Leverage Map
- Priority impact areas
- Effort vs Impact matrix

## External Data Access
❌ **None** - This agent operates on internal data only

## Permissions Required
- None (internal processing only)

## Agent Type
Internal reasoning agent - does not appear in external agent management UI

## Execution Context
- Runs after Situation Analyst completion
- Processes internal analysis data
- Generates strategic recommendations
