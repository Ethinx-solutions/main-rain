# Situation Analyst Agent

## Purpose
Understand the customer's reality by analyzing intake answers and archetype data to generate a comprehensive "Current Reality" narrative.

## Inputs
- Intake answers (user responses to onboarding questions)
- User archetype classification
- Historical usage patterns

## Outputs
- "Current Reality" narrative document
- Key insights and patterns identified
- Recommended focus areas

## External Data Access
❌ **None** - This agent operates on internal data only

## Permissions Required
- None (internal processing only)

## Agent Type
Internal reasoning agent - does not appear in external agent management UI

## Execution Context
- Runs during user onboarding completion
- Triggered by intake form submission
- Processes data locally without external API calls
