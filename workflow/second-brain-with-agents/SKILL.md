# Second Brain Dashboard with Agent System

## Overview
This workflow builds a comprehensive second brain application starting from a basic dashboard clone and extending it with a full ETHINX agent management system.

## Parameters
- **dashboard_url** (required): The reference dashboard URL to clone
- **deployment_platform** (optional, default: Vercel): Platform to deploy the application to
- **agent_count** (optional, default: 10): Total number of ETHINX agents to implement
- **external_services** (optional, default: Stripe, Supabase, Deployment, Audit): External services for agent integration
